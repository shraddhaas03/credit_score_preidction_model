# credit_score_preidction_model

A machine learning regression project that predicts an individual's CIBIL credit score based on financial and credit-related 
factors such as age, monthly income, existing loans, EMI obligations, credit utilization, credit inquiries, late payments, bank account history, and employment type.

Project Overview

The goal of this project is to build a regression-based machine learning model that can estimate a CIBIL score from user-provided financial information.

Machine Learning Models

Three regression algorithms are trained and compared:

Linear Regression

Decision Tree Regression

Random Forest Regression

The models are evaluated using:

MAE (Mean Absolute Error)

RMSE (Root Mean Squared Error)

R² Score

A model comparison table is generated to compare the performance of all three approaches.

Model Analysis

The project includes an Actual vs. Predicted CIBIL Score visualization to examine how closely the Random Forest predictions match the actual scores.

A feature importance analysis is also performed using the Random Forest model to identify which input features contribute most to the model's predictions.

Project Objective

This project demonstrates an end-to-end machine learning regression workflow, from data preprocessing and feature engineering to model training, evaluation, visualization, and user-level prediction.
